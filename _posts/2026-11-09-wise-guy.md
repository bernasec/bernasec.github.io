Write-up do desafio de nível fácil do <a href="tryhackme.com/room/w1seguy" >TryHackMe - W1seguy</a>.

>Vamos utilizar aqui as ferramentas Kali, SquawquerVPN, Cyberchef.

Antes mesmo de começar de fato o desafio nós temos que analisar um código fonte disponibilizado pela plataforma sendo ele a primeira tarefa de fato.

Vamos analisar parte por parte, juntos.
<img src="assets\img\w1seguy\source-code.webp">
<p>
Aqui podemos notar com a parte principal, que ele está crpitografando a flag real por cima de flag falsa junto com uma key para XOR, parece difícil mas é bem simples!
</p>
<p>
Como ja foi mostrado a chave tem o comprimento de 5 chars, que você já ate sabe por onde procurar essa chave já que eles nos deu uma dica de como virá a flag.
<br>Sendo assim só temos que usar o <strong>THM{}</strong> para descobrir a chave verdadeira, onde será 4 primeiros chars e o último char, que representa o padrão da flag.
</p>
<p>
Para começar somente se conectar no server via netcat. <br>
'''
nc 10.65.158.111 1337
'''
</p>
<p>
Com isso ele te pede uma flag falsa que é esta que ele te passou via XOR com THM{}.
Para fazer isso vamos utilizar o site <a href="gchq.github.io/CyberChef/">CyberChef</a>, um site muito bom para esses desafios de cryptografia por sinal.
Agora somente escolher o para ler hex e junto com XOR decrypt, a página deve ficar assim:<br>
<img src="assets\img\w1seguy\cyberchef-page.webp"><br>
Depois disso colocamos no input o texto crpitografo passado e colocar na key <strong>THM{}</strong>.<br>
<img src="assets\img\w1seguy\cyberchef-antes-da-key.webp"><br>
Agora pegamos os caracteres necessarios para a key real e colocamos ela no campo key para adquirir a flag 1!<br>
<img src="assets\img\w1seguy\final.webp"><br>
E só passar a mesma key na CLI também para pegar a flag 2 final! <br>
Desafio bem legal, curto e rapido se ja tiver feito algo parecido antes, na primeira vez apanhei bastante até descobrir esse site para fazer XOR, mas no fim prática e treinamento mesmo com write-up para ajudar vai trazer algum conhecimento!
</p>
